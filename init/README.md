# Assignment 1 — BKMove Starter

| Question | Main file | Public check |
|---|---|---|
| Q1 — Singly Linked List | `SLinkedList.h` | `make q1` |
| Q2 — Circular Linked List | `CircularLinkedList.h` | `make q2` |
| Q3 — Bus Route | `BusRoute.cpp` | `make q3` |
| Q4 — Quick Sort | `QuickSort.h` | `make q4` |
| Q5 — BKMove Search | `BKMove.cpp` | `make q5` |

```bash
make q1
make q2
make q3
make q4
make q5
make all
```

Do not change the public APIs in `IList.h`, `ISort.h`, `BusRoute.h`, `BKMove.h`, or `main.h`.

The Makefile checks the container/sorting restrictions required by the assignment.
The public tests are part of the starter and should be read together with the skeleton.

Run one public test group while debugging:

```bash
make q3 TEST=4
```
